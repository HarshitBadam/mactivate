## Highlights

Mactivate 1.0.3 is a packaging fix: the app icon now ships correctly with the macOS release build.

### Packaging

- Bundled the Mactivate icon with the release build, so installed copies show the intended app icon instead of the default one.

## Install

### Homebrew

New installation:

```bash
brew tap HarshitBadam/mactivate
brew trust --cask HarshitBadam/mactivate/mactivate
brew install --cask mactivate
```

Existing installation:

```bash
brew update
brew upgrade --cask mactivate
```

### Disk image

Download `Mactivate-1.0.3.dmg` from the assets below and drag Mactivate into Applications.

## Compatibility

- macOS 13 or newer
- Apple Silicon MacBook
- Built-in motion and ambient-light sensors

## Security notice

Mactivate is distributed with ad-hoc signing and is not Apple-notarized. macOS may require approval under **System Settings → Privacy & Security → Open Anyway** after the first launch.

Do not disable Gatekeeper.

## Verification

The SHA-256 checksum is available in `Mactivate-1.0.3.dmg.sha256`.
