## Highlights

Mactivate 1.0.2 polishes the Configuration Window and improves the transition from the Notch Panel into settings.

### Configuration Window

- Aligned the palm-rest readiness status with its gesture rows.
- Restored the native macOS switch appearance with a clear enabled state.
- Ensured the Configuration Window opens in front of other applications.
- Added an initial “No tap detected yet” state to Diagnostics.

### Notch Panel

- The Notch Panel now closes when its gear button opens Configuration.
- Notch Hover remains enabled, allowing the panel to reopen normally.

## Install

### Homebrew

New installation:

```bash
brew tap HarshitBadam/mactivate
brew trust --cask HarshitBadam/mactivate/mactivate
brew install --cask mactivate
```

Existing installation:

```bash
brew update
brew upgrade --cask mactivate
```

### Disk image

Download `Mactivate-1.0.2.dmg` from the assets below and drag Mactivate into Applications.

## Compatibility

- macOS 13 or newer
- Apple Silicon MacBook
- Built-in motion and ambient-light sensors

## Security notice

Mactivate is distributed with ad-hoc signing and is not Apple-notarized. macOS may require approval under **System Settings → Privacy & Security → Open Anyway** after the first launch.

Do not disable Gatekeeper.

## Verification

The SHA-256 checksum is available in `Mactivate-1.0.2.dmg.sha256`.
